A script for easily converting .gim files to .png and vice versa.
The script works with official tools (GimConv.exe, GimView.exe)
Converting .png files to .gim using color palettes (rgba4444, rgba5551, rgba5650, rgba8888)

**What is a .gim file?**

A file with the .gim extension is a graphic image format used primarily in games for the PlayStation Portable (PSP) console.
